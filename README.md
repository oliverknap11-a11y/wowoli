# Wowoli — web

Verejné stránky hry **Wowoli** pre iPhone.

Beží na GitHub Pages: <https://oliverknap11-a11y.github.io/wowoli/>

| Stránka | Načo |
|---|---|
| `index.html` | úvodná stránka |
| `privacy.html` | zásady ochrany súkromia — **Apple ich vyžaduje ako funkčný odkaz** |
| `terms.html` | podmienky používania |
| `support.html` | podpora — **Apple ju vyžaduje tiež** |

> Tieto súbory sa generujú v projekte hry (priečinok `site/`).
> Keď meníš texty, meň ich tam a sem ich len prekopíruj — inak sa
> rozídu s tým, čo je napísané priamo v aplikácii.

`wowoli.svg` a `icon.png` sú vyexportované z vektorovej definície postavičky
príkazom `npm run brand`. Neupravuj ich ručne.
